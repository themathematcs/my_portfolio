Chrome and Windows might warn you. Here's why — and how to install safely.

TradeTrack Pro is a brand-new app. Microsoft hasn't seen it before, so Chrome's Safe Browsing and Windows SmartScreen flag every download until enough people install it without reporting problems. This is the same warning you see for new indie apps from any developer — not a sign anything is wrong with the file.

1 In Chrome

When Chrome says "This file is dangerous":

  1. Click the small ⌄ arrow next to the file at the bottom
  2. Click Keep
  3. If asked again, click Keep anyway
2 When you double-click the installer

Windows SmartScreen shows "Windows protected your PC":

  1. Click More info (small grey link)
  2. Click Run anyway
  3. The installer wizard opens
3 If your antivirus complains

Some antivirus tools (Avast, Bitdefender, Norton) flag unsigned installers heuristically. You can either:
